# Nova Companion

Помощник игрока NOVA RP для Windows: учёт общего баланса, панели поверх игры, заметки и законка по серверам.

## Скачать

Для первого запуска скачайте [Nova-Portable.zip — базовый полный архив](https://github.com/Spel-Alleen/NovaCompanion/releases/download/v0.2.1/Nova-Portable.zip), целиком распакуйте его и запустите `Nova/NovaCompanion.exe`. Затем установите последнюю версию через настройки приложения. Архив около 1,3 ГБ, включая бесплатную локальную модель; последующие пакеты обновления намного меньше. Отдельная установка Python или Ollama не нужна. Поставка проверена на Windows 11 x64.

Файлы `Nova-update-…zip` предназначены для обновления существующей программы, а не для первого запуска. [Все выпуски](https://github.com/Spel-Alleen/NovaCompanion/releases).

## Возможности

- Считывание наличных и банка с интерфейса NOVA, результат за день, неделю и месяц.
- Главное окно и отдельные панели финансов, заметок и законки.
- Перемещение и изменение размера панелей по горячей клавише.
- Раздельные документы и заметки для Mirage, New Era и Horizon.
- Поиск статей, локальный ИИ и автоматические сводки процедур по загруженным документам выбранного сервера.
- Диалог с историей, уточняющими вопросами и продолжениями разговора. Главное окно и оверлей показывают общий чат выбранного сервера.
- Короткие ответы с источниками; подробные статьи раскрываются отдельно. Enter отправляет сообщение, Shift+Enter добавляет строку.
- Для Mirage включены 29 документов. Для других серверов нужно импортировать их собственную законку.
- Общие обновления приложения и законки через GitHub Releases, с проверкой подписи автора.

Автоматическая сводка порядка задержания извлекает основания, последовательность, права, обязанности, сроки и особые случаи из самого кодекса. Номера статей другого сервера не подставляются. Оценка конкретного спорного случая требует фактов; локальная модель может ошибаться.

## Управление

| Сочетание | Действие |
|---|---|
| Ctrl+Shift+F6 | Главное окно |
| Ctrl+Shift+F7 | Финансы |
| Ctrl+Shift+F8 | Заметки |
| Ctrl+Shift+F9 | Законка |
| Ctrl+Shift+F10 | Режим настройки оверлея / сохранить |

Сочетания изменяются в настройках. Для окон поверх игры используйте оконный режим или режим без рамки. Крестик главного окна скрывает его; полный выход доступен через значок N рядом с часами.

## Обновления и личные данные

Проверка новых версий выполняется при запуске и затем раз в четыре часа, если включена. Для установки нажмите «Установить и перезапустить» в настройках. Пакет проверяется по подписи автора, перед установкой создаётся резервная копия.

Финансы, заметки и личные настройки хранятся локально в `%LOCALAPPDATA%\NovaCompanion`. Они не публикуются и не включаются в общие выпуски. Снимки экрана не отправляются в интернет. Обновление включает код и общую библиотеку законов; изменения моделей и среды выполнения требуют нового полного архива.

## Исходники и зависимости

`source` содержит код приложения и файла запуска; `library` — поставляемую библиотеку. Рабочая поставка включает переносимый Python, Qt for Python, Windows OCR, llama.cpp и Qwen2.5-1.5B-Instruct-GGUF. Лицензии зависимостей приложены в полном архиве. Правила сервера приведены по предоставленным сохранённым страницам форума NOVA RP; тексты и схемы могут изменяться на стороне сервера.
